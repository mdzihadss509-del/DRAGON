# Dragon Minecraft Marketplace

A Next.js 15 + React 19 marketplace frontend for Minecraft creators, server owners and players.

## Product categories
- Server plans and ready-developed servers
- Mods and modpacks
- Plugins
- Texture packs and shaders
- Worlds and maps
- Development and support services

## Local development
```bash
npm install
npm run dev
```

## Current implementation
- Responsive marketplace landing page
- Category browsing and filtering
- Product search
- Product preview modal with image
- Demo cart state
- Arctic Rainbow visual theme (white-led UI, electric blue, purple and rainbow accents)

## Important limitations
This is an initial frontend prototype. Product records and prices are sample data. Authentication, creator uploads, persistent database, real payment/checkout, secure file delivery, reviews, moderation and admin management are not implemented yet. Product preview images currently use remote demo image URLs.
